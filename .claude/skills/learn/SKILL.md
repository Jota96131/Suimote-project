# /learn — 学んだことをノートに保存

会話中に質問・説明された概念を `learning-notes/` にmarkdownファイルとして保存してください。

## 手順

1. `$ARGUMENTS` のトピックについて、今の会話で説明した内容を振り返る
2. 既存のノート（`learning-notes/`内のファイル）のスタイルに合わせて整理する
3. `learning-notes/` にファイルを作成する（ファイル名は英語のケバブケース、例: `rpc-functions.md`）

## 出力フォーマット

```markdown
# 〇〇とは

1〜2文の簡潔な説明。

## たとえ

日常のものに例えた説明（赤ちゃんでもわかるレベル）。

## 具体例

コード例や使い方。プロジェクト（スイモテ）に関連する例があればそれを優先。

## なぜ使うのか

| 使わない場合 | 使う場合 |
|---|---|
| ... | ... |

## 一言まとめ

1文でまとめる。
```

## ルール

- 会話中に説明した内容をベースにする（新しく調べ直さない）
- 既存のノートと重複する場合は、既存ファイルを更新する
- 専門用語が出てきたら括弧書きで簡単な補足をつける
- ファイル作成後、作成したファイルパスを表示する
