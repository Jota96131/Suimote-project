# プレースホルダー（placeholder）とは

## ひとことで言うと

**「あとで本物に差し替える、仮の入れもの」**。「ここに何かが入りますよ」という目印。

## よくある例

### 1. 入力フォーム
```html
<input placeholder="メールアドレスを入力してください" />
```
テキストボックスに薄いグレーで表示される案内文字。ユーザーが入力し始めると消える。

### 2. 画像のプレースホルダー
画像が読み込まれるまでの間に表示される灰色のボックスやスケルトン表示。

### 3. コード中のプレースホルダー
```js
const apiUrl = "https://example.com/api"  // ← 仮のURL
const userName = "TODO: ここにユーザー名"
```
まだ決まっていない値を一時的に入れておくもの。

### 4. SQLやテンプレートのプレースホルダー
```sql
SELECT * FROM users WHERE id = ?   -- ? がプレースホルダー
```
実行時に実際の値が埋め込まれる。SQLインジェクション対策としても重要。
