# デモGIF撮影ガイド

## 準備

1. アプリをローカル起動 (`npm run dev`)
2. 画面録画ツールを用意（macOSなら `Kap` が無料でGIF書き出しできる）
3. ブラウザのDevToolsでスマホ表示にする（iPhone SEやiPhone 14サイズ）
4. テスト用アカウント2つ用意（マッチング撮影用に相互いいねが必要）

## 撮影

### GIF 1: 練習記録のCRUD（追加 → 一覧 → 編集 → 削除）

1. `/records/new` で記録を追加
2. `/records` の一覧に反映されたのを確認
3. 記録をタップ → 詳細表示
4. 編集ボタン → 内容を変更して保存
5. 削除ボタン → 確認ダイアログ → 削除

### GIF 2: プロフィール編集 → マッチングON

1. `/profile` を表示
2. 編集ボタン → ニックネーム・エリア等を入力
3. マッチングONに切り替え
4. 保存 → プロフィールに反映

### GIF 3: ユーザー一覧 → いいね → マッチ成立

1. `/users` でエリア内のユーザー一覧を表示
2. 相手のカードでいいねボタンを押す
3. （相手側もいいね済みなら）マッチ成立ダイアログが表示

### GIF 4: マッチ一覧 → 相手のプロフィール

1. `/matches` でマッチ一覧を表示
2. 相手をタップ → プロフィール詳細を表示

## 撮影後

1. GIFを適切なサイズにトリミング（幅300〜400px程度）
2. Qiitaの編集画面にドラッグ&ドロップでアップロード
3. 生成されたURLを記事の `<!-- GIF -->` 部分に貼る
