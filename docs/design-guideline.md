# Suimote デザインガイドライン

## ターゲットユーザー
- 年齢層: 20代〜30代
- 性別: 男女
- 水泳レベル: 初心者〜週1-2回の趣味レベル、ナイトプール層も含む

## コンセプト
「おしゃれ・夜っぽい」— ナイトプールの雰囲気を感じるダーク系UI

| 用途 | カラー | 説明 |

## フォント
- 日本語: システムフォント（Hiragino Sans / Noto Sans JP）
- 英数字: Geist（既に導入済み）

## UIの特徴
- ダークモードベース
- カードに微妙なグラデーションやグロー（光る）エフェクト
- ボタンはネオンブルーのグラデーション
- いいね・マッチ系はネオンピンク
- 角丸は大きめ（12px〜16px）
- 余白はゆったり
